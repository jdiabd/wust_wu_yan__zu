# 🐸 合成大奶蛙 · Milk Frog Merge

> 一个「合成大西瓜」玩法的网页小游戏：把奶蛙丢进玻璃缸，两只相同的奶蛙撞在一起就会合成更大的奶蛙，一路合成到传说中的 **神奶蛙**。
>
> **纯原生 HTML / CSS / JavaScript，零第三方依赖，自研圆形刚体物理引擎，双击就能玩。**

**在线试玩：** https://jdiabd.github.io/wust_wu_yan_zu/

---

## 📦 关于这个仓库

**整个游戏只有一个文件：`index.html`（约 1.3 MB）。**

CSS、6 个 JS 模块、11 张奶蛙贴图、图标，全部内联在这一个 HTML 里（图片是 base64）。所以：

- 不需要构建、不需要 npm、不需要服务器
- 下载下来双击就能玩，断网也能玩
- 传到 GitHub Pages 只需要这**一个**文件

文件内部的代码仍然按模块用注释分段，从上到下依次是：

| 段落 | 内容 |
| --- | --- |
| `<style>` | 主题变量、布局、覆盖层、响应式 |
| `var IMG` | 11 张贴图的 base64 数据 |
| `config.js` 段 | 棋盘尺寸、11 级奶蛙参数（半径/分数）、物理参数 |
| `physics.js` 段 | 圆形刚体物理引擎：`World` / `Body` / `findMergePairs` |
| `audio.js` 段 | WebAudio 合成音效（没有任何音频文件） |
| `fx.js` 段 | 粒子 / 冲击波 / 飘字 / 屏幕震动 |
| `game.js` 段 | 状态机、落子、合成、计分、Canvas 绘制 |
| `main.js` 段 | 启动、DOM 绑定、输入、主循环 |

想改数值：搜索 `const CONFIG`（物理手感）或 `const LEVELS`（11 级的半径和分数）。

## 🕹 玩法

| 操作 | 说明 |
| --- | --- |
| 移动鼠标 / 手指拖动 / `←` `→` | 左右瞄准，虚线圆圈是落点预测 |
| 点击 / 松手 / `空格` | 投下奶蛙 |
| `P` / `Esc` | 暂停 / 继续 |
| `R` | 重新开始 |
| `M` | 静音开关 |

**规则**

1. 两只**相同等级**的奶蛙碰到一起 → 原地合成下一级奶蛙，并获得分数。
2. 11 级进化链：奶蛙蛋 → 小奶蛙 → 鼠奶蛙 → 鸡奶蛙 → 狗奶蛙 → 马奶蛙 → 兔奶蛙 → 抱臂奶蛙 → 天使奶蛙 → 狂笑奶蛙 → **神奶蛙**。
3. 两只「神奶蛙」相撞会一起消失，额外奖励 500 分（致敬大西瓜的"封神"隐藏操作）。
4. 1.1 秒内连续合成会累积**连击倍率**，最高 ×3。
5. 奶蛙堆过红色虚线并静止 1.1 秒 → 游戏结束；最高分保存在 `localStorage`。

## ✨ 特性

- 🧲 **自研圆形刚体物理**：位置修正 + 法向冲量 + 切向摩擦，4 子步 × 6 次迭代，堆叠稳定不抖动。
- 🖼 **11 张透明贴图**：网上那只奶蛙的现成渲染图，一眼认得出；不同形态配不同动作，堆在一起很有戏。
- 🎯 **落点预测**：垂直虚线 + 虚线圈，投递前就能看到会落在哪里。
- 💥 **手感反馈**：合成粒子、冲击波、飘分、屏幕震动、等级越高音效越亮。
- 🔊 **纯代码合成音效**：WebAudio 振荡器实时合成，仓库里一个音频文件都没有。
- 📱 **全端适配**：桌面 / 手机 / 平板自适应；鼠标、触摸、键盘三套操作。
- 🧩 **图鉴与解锁**：侧栏 11 级进化图鉴，解锁过的奶蛙会点亮，进度写入本地存储。
- ♿ **细节**：`prefers-reduced-motion` 降级动画、按钮 aria-label、切后台自动暂停。

## 🛠 技术实现

### 物理引擎

合成类游戏只需要「圆 vs 圆」「圆 vs 墙」，所以没有引入 Matter.js，而是写了一个约 200 行的专用引擎（搜索 `class World`）：

1. **固定步长**：主循环用 1/60 秒累加器，物理再做 `substeps = 4` 次子步，保证低帧率下也不会穿模；
2. **半隐式欧拉积分**：`v += g·h`，`p += v·h`，并施加线性阻尼；
3. **约束求解**：每个子步迭代 `iterations = 6` 次，对每一对相交的圆
   - 沿法线做**位置修正**（留 `slop` 容差、只修正 85%，避免抖动）；
   - 若相互靠近则施加**法向冲量**（低速时恢复系数取 0，堆叠更稳）；
   - 用库仑摩擦模型施加**切向冲量**，防止奶蛙沿斜面一直下滑；
4. **墙体**：位置钳制 + 速度反弹（恢复系数 0.04）；
5. **合成判定**：`findMergePairs()` 在一帧内按 `id` 去重，保证同一只奶蛙一帧只合成一次。

### 渲染与性能

- 整个棋盘用一张 `Canvas` 绘制，逻辑坐标固定 420×620，按 `devicePixelRatio`（上限 2）缩放，CSS 尺寸由 JS 计算后**等比 contain**，任何屏幕都不会拉伸变形。
- 主循环固定步长更新、每帧渲染一次；50 个刚体时单帧物理耗时 **< 0.2ms**。
- 贴图是一次性预加载的 320×320 PNG（内联后按圆形刚体半径缩放），无逐帧解析。
